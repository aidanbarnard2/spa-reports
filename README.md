# spa-reports

Report pages from Saint Paul Agency. Each page is encrypted and opens only with its password.

Each client's page lives in a folder named after the client (for example `borton-volvo/`). The older folders (`dashboard/`, `microsoft/`, `dashboard-2/`, `dashboard-3/`, `dashboard-4/`) only forward to the new ones, so links sent before Oct 19, 2026 keep working.
